# EventLens

Проверка того, помогает ли смысл Telegram-событий прогнозировать будущий риск Bitcoin.

Исследуем два признака: **новизну события** и **его тип/статус**. Сравниваем их с рыночными данными, активностью сообщений и простым sentiment. Устойчивое преимущество семантики пока не установлено.

## Текущее состояние

В проекте сохранены Telegram-тексты, TBSA-аннотации, рыночные таблицы и исторические эксперименты с графами и ML. Аудит выявил ошибки состава корпуса, временных признаков и GNN-датасета. Старые презентации и метрики отражают этапы исследования и не являются подтверждением прогностического эффекта.

Ближайшая работа — один небольшой воспроизводимый эксперимент: общий корпус, регулярный рынок, строго будущая цель, простые baseline и несколько смысловых признаков. Новый benchmark ещё не реализован; проверенная команда запуска появится вместе с ним.

Исходные данные и старые результаты сохраняются. Перед запуском legacy-скриптов следует проверить побочные эффекты: некоторые обращаются к платным API, изменяют Neo4j или перезаписывают файлы.

## Состав репозитория

- `scripts/` — исходники исторических экспериментов для анализа и выборочного переиспользования.
- `multi_asset/` — историческая попытка проверки других активов; не часть нового benchmark.
- `results/` — небольшие исторические метрики, на которые ссылается аудит.
- `data/README.md` — какие локальные данные нужны; тексты, API-ответы и модели в GitHub не публикуются.
- `.env.example` — имена локальных настроек без ключей.

Репозиторий не содержит полного датасета и готового нового benchmark. Зависимости legacy-скриптов различаются; проверенная минимальная установка будет добавлена вместе с новым экспериментом.
